# QuickSnap

轻量、快速、低内存的 macOS 原生截图与离线 OCR 工具（零第三方依赖，纯 Swift + AppKit / SwiftUI + ScreenCaptureKit + Vision）。

## 核心功能

- **多模式截图**：区域选框截图（`⌘⇧A`）、快捷离线 OCR（`⌘⇧O`）、全屏截图（`⌘⇧F`），兼容多显示器与 Retina 原生清晰度
- **窗口自动识别**：框选前鼠标悬停自动高亮目标窗口，单击即可整窗捕获
- **像素放大镜 & 取色器**：实时显示局部像素放大视图、`HEX / RGB` 色值（`Shift` 切换格式，`C` 复制色值）
- **基础标注工具**：矩形、椭圆、箭头、画笔、半透明荧光笔、惰性低内存马赛克、行内文字 `T`、自动递增序号 ①②③、6 色与 3 档线宽、撤销/重做（`⌘Z` / `⌘⇧Z`）
- **离线中英文 OCR**：基于 Apple `Vision`，本地神经引擎识别中英混排文字，支持微调编辑、置顶与一键复制
- **桌面固定贴图（Pin）**：按 `⌘P` 或工具栏图钉按钮将截图原位悬浮置顶在屏幕，支持单击直接拖动、四角拖拽/滚轮/双指捏合缩放、透明度调节与右键菜单
- **灵活导出与偏好设置**：`Enter`/`⌘C` 复制到剪贴板，`⌘S` 弹出原生保存对话框选择保存位置（PNG/JPEG），支持自定义全局热键与登录自启动

## 安装使用

### 方式一：DMG 安装
1. 双击打开 `dist/QuickSnap.dmg`，将 `QuickSnap.app` 拖入 `Applications` 文件夹。
2. 若首次打开受 Gatekeeper 拦截，右键应用选择「打开」或在「系统设置 → 隐私与安全性」中点击「仍要打开」。
3. 首次截图时按提示在「系统设置 → 隐私与安全性 → 屏幕录制」中勾选 `QuickSnap`（全局快捷键基于 Carbon，无需辅助功能权限）。

### 方式二：源码构建与打包
```bash
# 运行单元测试
swift test

# 生成 .app 与 .dmg（输出至 dist/）
./scripts/build_dmg.sh
```

> 本地开发时，`scripts/build_app.sh` 会自动检测钥匙串中的 `QuickSnap Code Signing` 代码签名证书；若不存在则自动回退到临时签名（`-`）。使用固定证书签名后，覆盖升级应用无需反复重授屏幕录制权限。
